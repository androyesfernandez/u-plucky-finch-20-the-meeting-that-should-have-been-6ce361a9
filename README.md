Nine people spent an hour in a room, and the only thing the meeting produced was an email describing the meeting — the very email that could have replaced the meeting in the first place.

## Run

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), with no trailing newline.
